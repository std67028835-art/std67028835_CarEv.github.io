เกี่ยวกับ Tesla Model 3 Standard

เป็นรถยนต์ไฟฟ้าสไตล์ซีดานรุ่นเริ่มต้น เน้นความคุ้มค่าสูงสุด ให้สมรรถนะการขับขี่ที่คล่องตัว และคงเอกลักษณ์เทคโนโลยีอันทันสมัยของ Tesla ในราคาที่เข้าถึงได้ง่ายที่สุด

  • จุดเด่นเฉพาะรุ่นย่อย : ขับเคลื่อนล้อหลังด้วยมอเตอร์เดี่ยว, ใช้เบาะผ้าสลับหนัง, ฝาครอบล้อดีไซน์ Prismata และเป็นรุ่นที่ราคาเข้าถึงง่ายที่สุดในไลน์อัปของ Model 3

  • ดีไซน์และฟีเจอร์ไฮไลต์ : หน้าจอกลางสัมผัสขนาด 15.4 นิ้ว, หลังคากระจกพาโนรามิกแบบกันความร้อน, กระโปรงหน้าเก็บสัมภาระได้ และรองรับระบบช่วยขับขี่ Autopilot

  • สิทธิประโยชน์และของแถม : รองรับการใช้งาน Tesla App ควบคุมตัวรถระยะไกล, เข้าถึงเครือข่ายสถานี Tesla Supercharger ทั่วประเทศ และอัปเดตซอฟต์แวร์แบบ Over-the-Air (OTA) สม่ำเสมอ

เกี่ยวกับ Tesla Model 3 Premium

เป็นรถยนต์ไฟฟ้าสไตล์ซีดานพรีเมียม ขับเคลื่อนล้อหลังที่อัปเกรดความหรูหราและความสบายภายในห้องโดยสารแบบครบครัน มอบความนุ่มนวลและฟังก์ชันการใช้งานระดับพรีเมียม

  • สิ่งที่อัปเกรดเพิ่มจากรุ่น Standard : อัปเกรดเบาะหนังเจาะรูพร้อมระบบระบายอากาศ, เพิ่มหน้าจอควบคุมด้านหลังขนาด 8 นิ้ว, เพิ่มไฟสร้างบรรยากาศ Ambient Light, อัปเกรดระบบเสียงลำโพง 9 ตำแหน่ง และโช้คอัพปรับความหน่วงตามความถี่

  • ดีไซน์และฟีเจอร์ไฮไลต์ : หน้าจอกลางสัมผัสขนาด 15.4 นิ้ว, หลังคากระจกพาโนรามิกแบบกันความร้อน, กระโปรงหน้าเก็บสัมภาระได้ และรองรับระบบช่วยขับขี่ Autopilot

  • สิทธิประโยชน์และของแถม : รองรับการใช้งาน Tesla App ควบคุมตัวรถระยะไกล, เข้าถึงเครือข่ายสถานี Tesla Supercharger ทั่วประเทศ และอัปเดตซอฟต์แวร์แบบ Over-the-Air (OTA) สม่ำเสมอ

เกี่ยวกับ Tesla Model 3 Performance

เป็นรถยนต์ไฟฟ้าสไตล์สปอร์ตซีดานสมรรถนะสูง ขับเคลื่อน 4 ล้อ มอเตอร์คู่ มอบอัตราเร่งอันทรงพลังระดับซูเปอร์คาร์ ตกแต่งดีไซน์ดุดันรอบคันทั้งภายนอกและภายใน

  • สิ่งที่อัปเกรดเพิ่มจากรุ่น Premium : ปรับแต่งมอเตอร์คู่ให้พละกำลังสูงสุด, ระบบขับเคลื่อน 4 ล้อ (AWD), ระบบกันสะเทือนแบบปรับได้ (Adaptive Suspension), เบาะนั่งสไตล์สปอร์ต, สปอยเลอร์หลังคาร์บอนไฟเบอร์ และล้อ Forged

  • ดีไซน์และฟีเจอร์ไฮไลต์ : หน้าจอกลางสัมผัสขนาด 15.4 นิ้ว, หน้าจอควบคุมด้านหลังขนาด 8 นิ้ว, หลังคากระจกพาโนรามิกแบบกันความร้อน, ระบบเสียงรอบทิศทาง, กระโปรงหน้าเก็บสัมภาระได้ และรองรับระบบช่วยขับขี่ Autopilot

  • สิทธิประโยชน์และของแถม : รองรับการใช้งาน Tesla App ควบคุมตัวรถระยะไกล, เข้าถึงเครือข่ายสถานี Tesla Supercharger ทั่วประเทศ และอัปเดตซอฟต์แวร์แบบ Over-the-Air (OTA) สม่ำเสมอ
